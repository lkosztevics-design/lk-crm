⚙ Настройки

Ключ Groq API (опционально) — для настоящей AI-генерации шапки. Без ключа помощник соберёт черновик локально.

👥 Команда

Все люди компании в одном месте: имя, должность, почта и доступ в CRM. По почте система узнаёт человека и даёт ему кнопки «про себя» (взять задачу, «я участвую»).

С почтой — сразу получит доступ и пароль для входа. Без почты — попадёт в список «без входа».
Роли: кнопка «☆ Менеджер» в строке человека делает его менеджером проектов — он ведёт все программы (правит шапки, назначает исполнителей, меняет руководителей). «🔑 вход» — дать доступ в CRM, «⛔ вход» — забрать, «✕ архив» — убрать из команды.
