⚙ Настройки

Ключ Groq API (опционально) — для настоящей AI-генерации шапки. Без ключа помощник соберёт черновик локально.

Ключ администратора сохраняется в общей базе, чтобы работал у всей команды. Перед первым сохранением ключа владелец должен один раз запустить meta.sql (Шаг Е-1 в инструкции по установке) — иначе таблица настроек открыта на чтение из интернета.
